# Apuntar al objetivo 

Es un juego de un tanque que mata alienígenas.


## Estudiantes
- David Díaz
- Alan Argotte

## Requirimientos

- Node.js 18 o más actual
- npm

## Run

1. Instala dependencias

   ```
   npm install
   ```

2. Empieza el servidor

   ```
   npm run dev
   ```

3. Abre `http://localhost:5173` en tu navegador.

## Controles

-  ```← →```  Para movimiento horizontal
-  ```↑ ↓```  Para movimiento del cañón
-  ```1 2 3```   Para cambiar la fuerza del lanzamiento
-  ```F``` Para cambiar la fuerza de lanzamiento una por una
-  ```Space```  Para disparar
-  ```R``` Para resetear
-  ```C``` Para cambiar la cámara a puntos específicos
-  ```M``` Para detener o prender la música
-  ```Numpad 4  Numpad 6``` Para mover la cámara alrededor del eje Y
